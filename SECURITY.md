# Security Policy

## Scope

This repository is a portfolio and demonstration application. It uses fictional demonstration workforce and competence data and is not a production workforce-management system.

## Data safety

Do not commit:

- real employee data
- patient data
- credentials or secrets
- production connection strings
- access tokens

Use fictional data for local development and demonstrations.

## Reporting

If you identify a security issue in the repository, please report it privately to the repository owner rather than publishing sensitive details in a public issue.

## Limitations

The application is not presented as production-ready. Authentication, authorisation, production secret management, network hardening and formal threat modelling are outside the current scope.
